# Jarvis 桌面 Agent

[English](README.md) · [快速开始](docs/QUICKSTART.md) · [贡献指南](CONTRIBUTING.md)

Jarvis 桌面 Agent 是面向 Windows 的桌面自动化与研究服务。本公开版本包含独立的 `agent_service` 和十个 `run_jarvis_*.py` 启动器，不依赖语音运行时或 OpenClaw。

## 能力范围

- 搜索并读取受支持的网站，以引文核对说法并生成带来源的报告；登录与验证码由用户在本地手动完成。
- 创建、编辑、核验并交接受支持的 WPS Word/Excel 文档，包括有界表格和多工作表流程。自然语言编辑绑定实际观察到的位置，经计划审阅后生成副本并原生回读，保留原件。
- 将已核验的办公成果接入下一任务；支持的恢复流程重验已完成步骤，只执行剩余工作。
- 将受支持的 Office＋Windows 指令拆成2–4步有界清单；先确认拆分，再逐步审阅执行。已核验的办公成果整批向后传递，支持的恢复只续未完成步骤。
- 观察受支持的 Windows 窗口及控件，预览有界目标，并选择兼容的原生、Winapp 或 Windows-MCP 执行方式。回执记录实际路由；外部作用未知时停止，不自动重放。
- 可选的整窗图像辅助只帮助选择受审候选，须显式开启，不授予任意屏幕坐标操作权限。
- 匹配已审查能力，让适配器草案经过离线检查、审查、有界试运行和启用。

以上流程受来源、应用和证据契约约束。通用电脑自主操作、任意生成代码执行、任意文档布局以及完整语音一体化助手不在本桌面发行范围内。证据缺失或变化时可能要求澄清或停止。

办公执行还须通过原有的受审适配器资格或限次试运行门禁。演示成功不等于不限次启用；次数耗尽后须完成正式启用或新批次资格工程，才能开始新的执行。

本次更新增加受控 Windows 执行器、自然语言办公编辑与已核验续接。验证范围见[发布检查与限制](docs/RELEASE_CHECKS.md)；开发机验收与公开快照检查分别记录，私有证据夹具不随源码发布。

## 要求与安装

Windows 10/11、Python 3.12、Microsoft Edge，以及安装了 Writer 和 Spreadsheets 的 WPS Office。安装和启动示例见[快速开始](docs/QUICKSTART.md)。

尚未验证全新电脑上的安装。不同 Office 安装之间的 Word/Excel COM 兼容性尚未验收；本版本说明的是 WPS。桌面发行范围不包含语音、本地或云端模型权重、用户数据、凭证或私人历史。

## 云端模型与费用控制

云端调用需要所有者创建本地授权文件并配置本地 API 密钥。受支持的 DeepSeek 和 OpenAI 路径共用一份持久用量/费用账本。所选任务文字，以及明确开启时的窗口图像，可能发送给配置的提供方。

本地授权支持 `limited` 模式（纽约自然日和滚动24小时各人民币5元）或明确授权的 `unlimited` 模式（取消本地金额上限）。不限额不会提供平台余额，也不会取消供应商配额；记账失败仍停止调用，未知预留继续保留。不能更换账本或清空未知预留绕过停止。

密钥和授权文件仅保存在本地，不能提交。配置契约见[快速开始](docs/QUICKSTART.md)。费用是保守的本地记账，不是供应商精确账单。
